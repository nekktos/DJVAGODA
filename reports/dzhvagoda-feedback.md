# Отчёт по playtest-1 (macOS)

**Сборка:** playtest-1
**Платформа:** macOS
**За кого играл:** злодей
**Сколько игроков:** 1 (соло, две зоны — эльфы и стража — были пустыми)
**Сколько играл:** ~15 минут
**Лог:** прилагаю `godot.log` (~/Library/Application Support/Godot/app_userdata/DzhvaGoda/logs/godot.log)

---

## Установка

Инструкция из README про `xattr -dr com.apple.quarantine` сработала, но приложение всё равно не запустилось: система выдала «Launch failed». Причина — у бинаря `DzhvaGoda.app/Contents/MacOS/DzhvaGoda` не был установлен исполняемый бит. После `chmod +x` на этот файл всё поехало нормально.

Скорее всего, при упаковке архива права были потеряны. Стоит либо пересобирать zip с сохранением прав, либо добавить в README шаг `chmod +x`.

## Что работало

- Рубка деревьев и камней мечом, ресурсы копятся при себе.
- Склад достраивается, ресурсы в него перекладываются.
- Огненный шар (`3`) работает по обычным целям.
- Стратегический режим по `Tab` открывается.

## Что сломано или непонятно

1. **Караван не отправляется.** По `C` маршрут от склада к шахте рисуется нормально, `Enter` жму — визуально ничего не происходит, караван не выезжает, ресурсы в склад не поступают. Проверял с достроенным складом.

2. **Где брать железо — непонятно.** Пробовал бить всё подряд мечом, взаимодействовать с шахтой на `F` — не нашёл источник. В README про железо тоже ничего явно нет. Из-за этого дальше вся ветка недоступна: казарма и наём мечников (`T`) упираются в железо, армии нет — играть нечем.

3. **Во дворец императора нельзя зайти — нет дверей.** Обошёл здание по периметру, входа не нашёл. Из-за этого условие победы «простоять 20 секунд внутри» физически невыполнимо. Оббегал вокруг заметно дольше 20 секунд, победа не срабатывает. Для одиночного злодея это блокер всей сессии.

4. **Командир стражи во дворе дворца — бессмертный.** Прилетел из огненного шара, попадания без реакции, урона не заметил. Понимаю, что это, скорее всего, квестовый NPC для стражи, но для злодея это выглядит как баг: подсказки, что его трогать бесполезно, нет.

## Что не проверялось

Умереть за 15 минут не успел, поэтому ветку «смерть, ранения, лут-куча, возрождение, наблюдатель» не проверял. Эльфов и стражу — тоже не проверял, играл соло. Перемирие, сохранение после выхода, сеть — не проверял.

## Три вопроса из раздела 7

1. **Почему прекратил на ~15 минуте.** Упёрся в тупик: без железа армию собрать нельзя, во дворец без дверей не зайти, а бегать между складом и дворцом без прогресса надоело.
2. **Самая интересная сторона.** Злодей — стратегический слой + свой боец на карте выглядит сочно. Про эльфов и стражу не могу судить, не играл.
3. **Одну вещь изменить.** Сделать сессию проходимой соло: показать где брать железо (или дать альтернативу), и сделать дворец с дверьми. Сейчас злодей физически не может победить, даже если делать всё правильно.

## Отдельно ценно (по разделу 6)

- Не понял, где источник железа. Никаких подсказок в игре не увидел.
- Не понял, почему командир стражи не получает урона.
- Скучно стало ровно в тот момент, когда закончились доступные действия (склад построен, железа нет, войск нет, во дворец не зайти).
