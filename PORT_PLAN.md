# Перенос «ДжваГоды» на Unity

**Решение автора от 30.09.2026:** переносим игру с Godot 4.7.2 на Unity —
«всё и сразу», без пробного среза. Причины — все сразу: графика и ассеты, сеть
и Steam, команда и карьера, производительность.

**Ассеты не переносим** (ответ автора): модели, текстуры и звуки делаются в
Unity с нуля. До этого — серые заглушки из примитивов. Выбор и покупку ассетов в
Asset Store делает автор: нужен вход в его аккаунт.

**С Unity работаем через MCP** (ответ автора): редактор ведётся инструментами
MCP-моста, а не правкой файлов сцен руками.

**Godot-версия остаётся в репозитории** (`godot_project/`) как эталон
поведения, пока Unity-версия её не догонит. Все числа баланса, правила и
находки живых playtest'ов и «долгих партий» — там, в коде и комментариях.

## Что нужно от автора

1. **Unity Hub** (unity.com/download) и вход в аккаунт — лицензия Personal.
2. В Hub — **Unity 6 LTS** (6000.0.x) с модулями **Windows Build Support** и
   **Mac Build Support (Mono)**.
3. Сказать, когда установлено: дальше проект, MCP-мост и сборки — моя часть.

## Устройство

```
unity_project/                 Unity-проект
  Assets/DjvaGoda/
    Core/                      ПРАВИЛА ИГРЫ на чистом C#, без UnityEngine
      DjvaGoda.Core.asmdef     noEngineReferences: true
      Economy/ Combat/ Units/  ресурсы, постройки, ступени, лавки, оружие,
                               заклинания, строи, шахты…
    Game/                      Unity-слой: сцены, сеть, физика, навигация, UI
core_tests/                    проверки ядра без Unity (./core_tests/run.sh)
godot_project/                 эталон: прежняя версия
```

**Ядро — в подмножестве C# 5.** Его собирает системный `csc` .NET Framework 4,
который есть в Windows всегда: правила проверяются без редактора и без .NET SDK.
Для Unity (C# 9) это полностью валидный код.

**Решения по технологиям** (перенос устройства Godot-версии):

| Godot-версия | Unity |
|---|---|
| High-Level Multiplayer, «хост считает всё, клиент — своё движение» | Netcode for GameObjects + Unity Transport, та же модель прав |
| `@rpc` с проверкой отправителя | `ServerRpc`/`ClientRpc` (Rpc с SendTo) с проверкой отправителя |
| MultiplayerSynchronizer | `NetworkVariable` |
| MultiplayerSpawner | `NetworkObject` + спавн с сервера |
| сетка навигации с перепечкой в потоке | AI Navigation: `NavMeshSurface`, постройки — `NavMeshObstacle` с вырезанием |
| наборы `tools/*_test.gd` + `run_tests.sh` | ядро — `core_tests`; сцена — Unity Test Framework (PlayMode), прогон из командной строки |
| `build_playtest.ps1` | сборка из командной строки редактора (`-batchmode -executeMethod`) |
| Steam — нет | Steamworks (Facepunch) — после паритета |

## Порядок работ

Каждый шаг — с проверками и коммитом, как раньше.

1. ✅ **Ядро правил, часть 1:** ресурсы и цены, постройки и ступени, стороны и
   вражда, правило снаряжённости стражи, оружие, заклинания, строи, шахта с
   копателями. 17 проверок.
2. ⏳ **Установка Unity** — автор. Затем: проект, пакеты (Netcode, Transport,
   AI Navigation, Input System, Test Framework, URP), MCP-мост.
3. **Сеть и персонаж:** хост/подключение по IP, спавн, движение (считает
   клиент), камера из-за плеча и первое лицо, прыжок, бег, выносливость.
4. **Бой:** оружие, зоны попадания, здоровье, снаряды, заклинания, мана.
5. **Мир:** процедурная карта (зоны, плато с пандусом, форт, дворец, лес,
   шахты) — серыми примитивами.
6. **Экономика:** казна стороны, склад, постройки со стройкой и ступенями,
   батраки, обозы, шахты, лавки, кузня, голод.
7. **ИИ:** гарнизон, отряд, распорядитель, вожак; навигация.
8. **Ранения:** зоны на костях, отрыв и перебитые конечности, протезы.
9. **Цели партии:** захват дворца, выбывание сторон, командир и приказы,
   старейшина и задания, сохранения.
10. **Интерфейс:** HUD картинками, панель команд, окна построек и лавки,
    переназначаемые клавиши, обучение.
11. **Долгие партии** на Unity-версии — паритет по звеньям цепочки злодея.
12. **Сборка для тестеров** Windows и macOS.
13. **Ассеты** — по выбору автора, на место заглушек.

## Открытые вопросы переноса

- Unity 6 LTS или другая версия — по умолчанию 6 LTS.
- Какой MCP-мост ставить: по умолчанию **MCP for Unity** (пакет в проект +
  локальный Python-сервер через uv). На машине есть Python 3.14; Node и uv нет —
  uv ставится при подключении моста.
