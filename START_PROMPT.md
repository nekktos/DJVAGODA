Ты работаешь над проектом «ДжваГода» — 3D-экшен с RTS-элементами, мультиплеер, движок Godot 4 (GDScript), open world из 4 зон, 3 играбельные асимметричные фракции (эльфы / охрана дворца / злодей).

Полный дизайн-документ лежит в `GDD.md` в корне этой папки, краткий бриф — в `HANDOFF.md`. Прочитай оба файла целиком, прежде чем делать что-либо ещё.

Ключевые вещи, которые нужно держать в голове постоянно:

1. **Мультиплеер обязателен с первого дня** — это не одиночная игра с ботами. Другими фракциями (например, партизанами-эльфами против злодея) могут управлять реальные игроки. Планируем 2 игроков, P2P, один клиент — хост, через Godot High-Level Multiplayer API. Без выделенных серверов и матчмейкинга — это задача на будущее.
2. **Соло-разработка + AI-ассистент**, художников и аниматоров в команде нет — опираемся на бесплатные ассеты (Kenney.nl, Quaternius, Poly Haven, Mixamo). Стиль — стилизованный low-poly, осознанный выбор под этот способ разработки.
3. **Масштаб задуманного огромен** (см. GDD, раздел 9 — честная оценка сопоставима с командной онлайн-игрой на несколько лет). Двигаемся строго вертикальным срезом, этап за этапом, не пытайся сделать всё сразу и не добавляй фичи, которых нет в текущем этапе GDD.
4. Возрастной рейтинг проекта — 21+, кровь и расчленение показываем без цензуры (см. GDD, разделы 3-4) — это осознанное решение, не нужно смягчать при реализации.

## Твоя первая и единственная задача сейчас

Этап 0 из GDD (раздел 9): **сетевой фундамент**. Ничего другого не делать, пока это не работает стабильно.

- Пустая grey-box сцена в Godot (просто плоскость + пара кубов для ориентира).
- Два клиента (host + peer) подключаются друг к другу через Godot High-Level Multiplayer API.
- Оба видят синхронное движение персонажа друг друга — простое перемещение по сцене (WASD + возможно прыжок), без боя, без контента, без UI сверх минимума для подключения.

Не переходи к Этапу 1 (grey-box карты, переключение камеры экшен/стратегия), пока Этап 0 не работает стабильно на практике — то есть я реально смог его потестировать вдвоём (или в двух окнах на одной машине) и увидеть, что синхронизация не рассыпается.
