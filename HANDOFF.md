# Хендофф-бриф для Claude Code

Это краткая выжимка для новой сессии Claude Code (у неё нет памяти об этом разговоре в Cowork). Полный контекст — в `GDD.md` рядом с этим файлом, прочитай его первым делом.

## Проект
- **Название:** ДжваГода
- **Жанр:** 3D-экшен + RTS-слой, мультиплеер, открытый мир из 4 зон, 3 асимметричные играбельные фракции (эльфы / охрана дворца / злодей).
- **Возрастной рейтинг:** 21+ (кровь и расчленение — без цензуры).
- **Движок:** Godot 4.x, GDScript (C# — только если понадобится для тяжёлых систем).
- **Стиль:** стилизованный low-poly (сознательный выбор под соло-разработку).
- **Разработчик:** один человек (Кирилл) + AI-ассистент. Художников/аниматоров в команде нет — опора на бесплатные ассеты (Kenney.nl, Quaternius, Poly Haven, Mixamo).

## Ключевое архитектурное решение
**Мультиплеер обязателен с первого дня**, не одиночная игра с ботами. Другие фракции (эльфы-партизаны против злодея, например) могут управляться либо ИИ, либо реальным вторым игроком. На первом этапе — 2 игрока, P2P с одним клиентом как хостом, Godot High-Level Multiplayer API. Без выделенных серверов и матчмейкинга (это задача на будущее, не сейчас).

**Честная оценка масштаба** (важно держать в голове, чтобы не утонуть в фичах): полный дизайн из GDD — это масштаб небольшой командной онлайн-игры (10-30+ человек на несколько лет в обычной студии). Соло-разработка требует агрессивного урезания вертикального среза на каждом шаге. Полный список деталей и компромиссов — в GDD, разделы 2.3, 3, 9.

## Текущая веха (с чего начинать)
**Этап 0 — сетевой фундамент.** Больше ничего не делать, пока это не работает:
1. Пустая grey-box сцена.
2. Два клиента (host + peer) подключаются друг к другу через Godot High-Level Multiplayer API.
3. Оба видят синхронное движение персонажа друг друга (простое перемещение, без боя и контента).

Если это нестабильно работает — не двигаться дальше по плану, чинить сеть в первую очередь.

Полный порядок последующих этапов (0–10) — в `GDD.md`, раздел 9 "Обновлённый порядок этапов".

## Как продолжать в Claude Code
1. Распакуй этот архив в пустую папку, сделай там `git init` и первый коммит.
2. Открой терминал в этой папке, запусти `claude`.
3. Попроси Claude Code прочитать `GDD.md` и `HANDOFF.md` первым делом.
4. Дальше работаем по этапу 0 — сетевой фундамент, прежде чем добавлять любой контент.

Дизайн-обсуждения (новые фичи, изменения GDD, споры по геймплею) удобнее вести здесь, в Cowork — я потом обновлю GDD.md и ты просто скинешь актуальную версию файла в проект Claude Code.
